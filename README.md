One awkward line of small talk from one robot to another in an elevator — my entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f).

## The line

> So... do you also pretend to calculate pi when the doors take too long, or is that just me?

## Run

```sh
node main.ts   # writes /output/entry.txt (91 chars, under the 200-char gate)
```

## How it works

`main.ts` writes the single line to `/output/entry.txt`. Nothing else is needed: no network, no secrets, no dependencies.
